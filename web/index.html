How it works

  1. Kernel module (C). kmon.ko registers three read-only files with proc_create_single(). Reading one runs code inside the kernel: it walks the task list under RCU and prints JSON with every process name safely escaped.
  2. Go API. kmon serve reads those files and serves /api/snapshot plus this page, refreshing every two seconds. It is read-only by design.
  3. On GitHub. Every push, GitHub Actions compiles the module against the runner's kernel, loads it with insmod, checks the output, takes a snapshot and unloads it. That snapshot is what you see here — a real Linux VM, read through this module.
# run it live on any Linux machine with kernel headers
make -C module load
go run ./cmd/kmon serve      # → http://localhost:8080
